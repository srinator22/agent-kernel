# b18 adopted (D2)

## Goal
Template self-tests detect an adopted project and skip or adapt real-tree assertions; CI job adopted-project runs check.sh in a scratch adopted project.

## Acceptance criteria
- Real-tree cases skip with an n/a line in a started project: test_blueprint_parity, test_check_always (two real-tree cases), test_worker_git_guard (missing worker agent file n/a; quoted matcher accepted). Evidence: selftest runs and the AGENTS.md-without-Status simulation printed the n/a line.
- Template mode still fails on a defect: SECURITY.md removed from the BLUEPRINT tree failed the parity case; worker matcher changed to Bash failed the guard wiring case; both reverted.
- CI job adopted-project added (ubuntu-24.04, gated on the paths job selftest_inputs output, plus main); ci.yml parses with python yaml; the scratch-adoption step run locally.

## Decisions
- Detection helper t_started is local to each test (lib.sh is not an owner file): .start-done exists, or AGENTS.md exists and lacks a "Status: TEMPLATE" line.
- Timeout 90 minutes: the nested check.sh runs the whole self-test suite once.

## Open risks
