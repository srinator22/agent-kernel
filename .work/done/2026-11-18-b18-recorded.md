## Goal
Make "each faked external CLI is backed by one recorded real response" a check, and add the missing Recorded lines.

## Acceptance criteria
- A convention is defined: a comment line `# Recorded: <command> -> <response>` or `# Recorded: none - <reason>` in each test file that fakes an external CLI and in each fixtures/fake-*.sh. Evidence: tests/template/test_test_files.sh (fake_lint).
- The check fails naming the file and the fake when the line is missing. Evidence: first run failed on ten files (fail-first), synthetic cases in the test assert the names.
- Missing lines added without changing test logic. Evidence: comment-only diff in nine test files and fixtures/fake-ruff.sh.

## Decisions
- Detection is a text heuristic (mkshim, replaced subprocess.run, files written under bin/, $SB, $SHIM(S), $BIN); one Recorded line per file is the enforced minimum, per-command lines are given where a file fakes several tools (doctor).
- Repo-internal stand-ins (quickgate.sh, dream.sh, stack-check.sh) are not external CLIs and are out of scope.
- Real responses were taken on 2026-11-18 on the dev host; public CI metadata for 6e3e70b1 was read with gh api.
