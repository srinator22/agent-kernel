# b18 lessons group (worker G5)

## Goal

Close three backlog rows: a lessons pruning pass recorded in MAINTENANCE.log; a
lessons.sh check that fails a lesson with `used: 0` more than 45 days after its
approval (needs an `approved:` field); a session-context line when no maintain
pass was logged in 35 days. Then fold in the advisor's cohesion-audit findings.

## Acceptance criteria

- INDEX.md lines carry `approved: YYYY-MM-DD` right after `last:`, backfilled from git history -> docs/lessons/INDEX.md, method in docs/lessons/MAINTENANCE.log
- lessons.sh check: used 0 at 46 days fails, at 45 passes, used 1 old passes; missing or malformed approved fails; `[met]` warns with exit 0 -> tests/template/test_lessons.sh
- session-context.sh prints one line when the log has no `YYYY-MM-DD maintain:` entry in 35 days, silent when fresh -> tests/template/test_session_context.sh
- maintain pass run and recorded with per-lesson evidence -> docs/lessons/MAINTENANCE.log, .archive/lessons/
- start-reset-lessons.sh archives what it drops -> tests/template/test_start_reset_lessons.sh

## Decisions

- approved: is optional in the parsing regex so that its absence is reported by name, not as a generic missing-fields error.
- expire also ages a never-used lesson (last: -) from approved:, so `check` failure and `expire --apply` agree.
- New `lessons.sh archive <Lnnn> <reason>` for lessons whose content lives in a repo file (no [met] marker is true for them).
- Maintain-pass entry format: first line `YYYY-MM-DD maintain: <summary>`; expire and archive lines do not count. A missing log counts as no pass (prints the line).
- L019 cut to the unmechanized per-command MSYS_NO_PATHCONV rule; L016, L011 to L015 kept.
- UPSTREAM.md entries: four moved to PENDING.md (format minus applies-to), four archived with reasons.
