# Task: b18 reuse group - skip the template self-tests when their inputs are unchanged
Mode: standard
Branch: b18/reuse
Date: 2026-11-17

## Goal
Every full ./scripts/check.sh runs all template self-tests (step 4g), 20 to 60
minutes on Windows, even when no template file changed. Reuse a green result
when the declared inputs are unchanged; widen to a full run whenever an input
is unknown (no record, changed key, list missing, CI, CHECK_SELFTEST=full).

## Acceptance criteria
- [x] tests/template/selftest-inputs.list declares every repo path the self-tests read -> audit in the list header; completeness is proved by `scripts/selftest-reuse.sh verify-inputs` (CI job wired by group G3); not run on the real repo locally (it runs the whole suite)
- [x] scripts/selftest-reuse.sh key|check|record|verify-inputs -> tests/template/test_selftest_reuse.sh (44 cases)
- [x] check.sh 4g reuses and says so, runs otherwise, records on success outside CI, skips the path when the script or list is absent -> tests/template/test_check_always.sh sec_reuse
- [x] timing line `check.sh: timing: selftest <N>s|reused, stack <N>s, total <N>s` -> sec_reuse assertions
- [x] --fast prints a reason per selection (changed-test, owner:<path>, widen:<path>); deleted, renamed, lib.sh and fixture cases -> sec_fast additions in test_check_always.sh
- [x] fixtures/check.sh is a byte copy of check.sh -> cmp

## Decisions
- "exists:" prefix in the list: presence only, content not hashed, for BACKLOG.md, BUILD_NOTES.md and .work files that change every task and that no test reads for content; otherwise a project's cache would miss on every task.
- .work/done and .work/jobs content is not an input; .work/TASK.md is presence-only (the nested started-project case lints the same file in the outer run).
- Whole directories for scripts, tests/template, tests/docs, docs, .claude, .codex, .agents, .github, .archive; not the project's own tests/ or src.
- A path under scripts/, tests/template/, .claude/ or .codex/ that no longer exists (deleted or renamed) widens --fast to every test; a path every test names (lib.sh) widens too.
- The record lives in the git dir (git rev-parse --git-path selftest-pass): untracked, never synced, per worktree.
- python and ruff versions are not part of the key (brief names bash, git, uname); CHECK_SELFTEST=full covers an upgrade.
