# b18 adrbody: mechanize accepted-ADR body immutability

## Goal

docs/procedures/adr.md step 5: an accepted ADR's body is never rewritten; only the
Status line changes in place; later changes are appended `## Amendment YYYY-MM-DD`
sections. `scripts/adr.sh check` enforces it against the default branch.

## Acceptance criteria

- body_check compares each ADR present on origin/<default> with the working file: evidence in tests/template/test_adr.sh section "Accepted ADR bodies against the default branch" (passes: unchanged, status change, appended amendment(s), trailing whitespace and blank lines, colon-titled amendment, new ADR not on base).
- Fails with file, first differing line and fix: appended text without a heading, non-Amendment appended heading, undated Amendment heading, edited line, deleted line, mid-body insertion, truncation (same file).
- QUICK=1, no origin, failed fetch: skip message printed, exit 0 (same file).
- ./scripts/selftest.sh tests/template/test_adr.sh: PASS.

## Decisions

- Same base and skip points as origin_check; body_check runs at the end of origin_check, and each skip path prints a second "adr: body check skipped: ..." line.
- Amendment heading regex: `## Amendment YYYY-MM-DD` optionally followed by a space or colon and a title (ADR 0012 already uses a colon title).
- Status normalisation applies only before the first `## ` heading.
- An ADR deleted or renamed relative to base is not reported (out of scope).
