## Goal
Close four destructive-guard BACKLOG rows. The guard refuses the remaining hook-skipping routes it did not read (a persistent `git config core.hooksPath X`, and core.hooksPath given through GIT_CONFIG_COUNT/KEY_n/VALUE_n or GIT_CONFIG_PARAMETERS), an inline git alias (`git -c alias.X=... The guard stays bash 3.2 compatible and fails closed, and the test runs from the repo root as `/bin/bash tests/template/test_destructive_guard.sh` with the guard executed by the same bash.

## Non-goals
- Persistent aliases (`git config alias.X ...` then `git X`), `git config --edit`, a hand edit of a config file, include.path, GIT_CONFIG_GLOBAL/GIT_CONFIG_SYSTEM pointing at a file: documented limits.
- Kills fed through a pipe (Get-Process | Stop-Process, Get-CimInstance | Invoke-CimMethod): already a documented limit.
- `kill 0` and negative process-group IDs other than -1 (`kill -- -1234` stays allowed: a group the session started).
- The bash 3.2 run on a real macOS runner (the check group adds that CI job); ADR 0006's stale "needs bash 4.4" line (not this task's decision).

## Forms (L012: refuse and allow lists; forms outside them are limits)
Refuse:
- `git config core.hooksPath X`, with --global, --local, --system, --worktree, --file F, --add, --replace-all, the `set` subcommand, any letter case
- `GIT_CONFIG_COUNT=1 GIT_CONFIG_KEY_0=core.hooksPath GIT_CONFIG_VALUE_0=X git commit`, the same after `env`, `export GIT_CONFIG_KEY_0=core.hooksPath`, `GIT_CONFIG_PARAMETERS="'core.hooksPath'='X'" git commit`, PowerShell `$env:GIT_CONFIG_KEY_0='core.hooksPath'`, cmd `set GIT_CONFIG_KEY_0=core.hooksPath`
- `git -c alias.X='!cmd' X`, `git -c alias.X='push --force' X`, any case, `git --config-env=alias.X=ENV X`, `git --config-env alias.X=ENV X`
- `tskill NAME`, `tskill NAME /a`
- `wmic process where name='x' delete`, `wmic process where "name='x'" call terminate`, `wmic process where (name="x") delete`, `wmic /node:h process where name=x delete`
- `kill -9 -1`, `kill -KILL -1`, `kill -s KILL -1`, `kill -n 9 -1`, `kill -- -1`, `kill -9 1234 -1`
- `taskkill /FI "USERNAME eq x"`, `taskkill /F /FI "STATUS eq NOT RESPONDING"`, `taskkill /FI "WINDOWTITLE eq x*"`, `taskkill //FI ...`, `taskkill -fi ...`, `taskkill /FI "PID gt 1000"`
Allow:
- `git config user.name X`, `git config core.hooksPath` (read), `git config --get core.hooksPath`, `git config get core.hooksPath`, `git config --unset core.hooksPath`, `git config --list`, `git config alias.st status`
- `git -c core.autocrlf=false status`, `git -c user.name=x commit -m y`, `git --config-env=user.name=NAME commit`
- `GIT_CONFIG_COUNT=1 GIT_CONFIG_KEY_0=user.name GIT_CONFIG_VALUE_0=x git commit -m y`, `GIT_CONFIG_PARAMETERS="'user.name'='x'" git status`
- `kill 1234`, `kill -9 1234`, `kill -1 1234` (signal 1 to 1234), `kill -9 -- 1234`, `kill -- -1234`, `kill -l`
- `tskill 1234`, `taskkill /PID 1234`, `taskkill /F /T /PID 1234`
- `wmic process where processid=1234 delete`, `wmic process where "processid=1234" call terminate`, `wmic process 1234 call terminate`, `wmic process where "name='node.exe'" get processid`, `wmic process list brief`
