# b18 group G1 (measure): selftest timing, --shard, --write-weights

## Goal
Make the template self-tests measurable and shardable: per-file timing, deterministic LPT sharding over a weights file, and a generator for that file.

## Acceptance criteria and evidence
- Timing summary (slowest 5, wall) printed every run: test_selftest "the slowest-files line is printed", "the wall-clock line is printed", "the slowest line names five files".
- SELFTEST_TIMES writes one "<seconds> <path>" line per file that ran, overwriting: test_selftest "one line per file that ran (quarantined excluded)", "overwritten, not appended".
- --shard K/N: union complete and disjoint for N=1,2,3,5; deterministic; hand-computed greedy deal; median for a missing weight; stale/malformed weights line warns once; usage errors (TEST_FILE, bad K/N): all in test_selftest.
- --write-weights: sorted, header, round-trips into --shard: test_selftest.
- Seed weights file: tests/template/selftest-weights.txt, header says PROXY (assert/t_ok/t_bad/t_na call counts) and how to replace it with measured seconds.
- Run: ./scripts/selftest.sh tests/template/test_selftest.sh passes (160 cases); bash -n scripts/selftest.sh ok.

## Decisions
- Times are whole seconds (bash SECONDS), portable to bash 3.2.
- Weights under 0.01 count as 0.01 in the deal so zero-second files spread instead of all landing in shard 1.
- Median is taken over the weights known for the files in play.
- A shard with no files prints a note and exits 0 (N larger than the file count).
- --write-weights writes tests/template/selftest-weights.txt under the repo root and exits; it takes no other argument.
- test_selftest.sh unsets SELFTEST_TIMES at its start so inner fixture runs cannot overwrite an outer times file.
