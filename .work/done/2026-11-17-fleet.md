# Task: Fleet dream - the template reads the projects' UPSTREAM entries, dream reports and, with permission, transcript signals
Mode: standard
Branch: b17/fleet
Date: 2026-11-17

## Goal
Clear the P2 BACKLOG row "Fleet dream". In the template repository,
`scripts/dream.sh fleet` reads every project in the existing fleet list
(fleet.local.list, the list scripts/fleet.sh reads) without writing to it,
and writes one bounded digest to the template's gitignored
.work/dream/fleet/. The digest holds each project's open UPSTREAM.md
entries, its newest dream reports and its template version. Transcript
signals are added only with an explicit --transcripts flag, reduced by the
same code as a project's own digest. The dreamer agent, in fleet mode, turns
the digest into numbered template-change proposals that cite the project and
entry; the owner approves; approved items become template BACKLOG rows or
PENDING.md entries.

## Non-goals
- No second fleet list and no change to scripts/fleet.sh.
- No write into any project (no file, no git index refresh), no sending or clearing of UPSTREAM entries.
- No Outcome/scorecard tracking for fleet reports; the fleet dream keeps only its date and transcript offsets.
- No edit to BACKLOG.md, .work/TASK.md, scripts/check.sh's required list (another group owns it) or the AGENTS.md kernel.

## Budget
- Wall-clock: one working session
- Subagents / workflow runs: 0
- Retries per failing step: 2
- Escalate to human when: a project write would be needed, or the dreamer contract cannot take a fleet input
